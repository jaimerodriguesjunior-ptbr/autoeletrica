# Pendências da landing MB Garage

- A gravação `public/landingpage/demonstracao-laudo-os.mp4` mostra o campo do programa como **Serviços executados**. Quando o programa for atualizado para **Serviços a serem executados**, gravar novamente ou atualizar a demonstração e conferir a mensagem da landing.
- A gravação mostra uma simulação visual de preenchimento, criada pelo roteiro temporário `public/landingpage/roteiro-gravacao-os.js`; ela não demonstra reconhecimento de voz real. O roteiro pode ser removido após a produção de uma nova gravação.
